# CKD Severity Prediction

This repository contains a machine learning pipeline for predicting the severity of chronic kidney disease (CKD) using clinical and laboratory data.

## Overview

The project is based on a private dataset collected from a medical facility in Bangladesh. The objective is to support early assessment and severity classification of CKD using data-driven methods.

The main work is contained in:

- `CKD_Astar_Improved_Pipeline_v4.ipynb` – end-to-end notebook for data processing, modeling, and evaluation
